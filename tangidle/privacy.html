사천당가 키우기 개인정보처리방침

FIVE DUCK GAMES(이하 "회사")는 모바일 게임 「사천당가 키우기」(이하 "게임")를 이용하는 분의 개인정보를 아래와 같이 처리합니다.

시행일: 2026년 10월 3일

1. 처리하는 개인정보와 목적

항목언제목적필수 여부
계정 식별자(게임이 자동으로 만드는 무작위 ID)"게스트로 시작"을 누를 때계정 생성·유지, 클라우드 저장, 순위 기록서버 계정을 쓸 때 필수. "오프라인으로 시작"은 계정과 게임 진행을 서버에 보내지 않습니다.
게임 진행 기록(클라우드 저장 사본과 직전 사본 하나, 서버 수련·도전 기록)클라우드 저장·서버 콘텐츠를 쓸 때진행 백업과 복원, 서버 콘텐츠 제공선택
서버 도전 점수(사냥·폐관·현상·방어 도전), 비무 표시 이름(1~16자)과 전투력·편성 요약, 무림 공적 기여 기록서버 도전·비무·무림 공적에 참여할 때순위표 제공. 점수, 비무 표시 이름, 공개 ID가 다른 이용자에게 전달됩니다. 공개 ID는 계정 식별자와 별개인 무작위 값이며 화면에는 앞 8자만 표시됩니다선택
표시 이름 신고 기록(신고한 계정, 신고 당시 이름)이름을 신고할 때부적절한 이름 처리선택
접속 기록(IP 주소, 요청 시각·경로, 클라이언트 종류)과 IP에서 추정한 대략적인 위치(국가·지역·도시)앱을 실행할 때(공지·최소 버전 확인)와 서버 기능을 쓸 때공지 제공, 부정 이용 방지, 장애 대응(서버 운영 기록)자동 생성. "오프라인으로 시작"을 골라도 앱 실행 때 공지 확인 접속 기록은 남습니다

게임 계정을 만들 때 실명·전화번호·이메일을 요구하지 않으며, GPS 등 기기의 정확한 위치·연락처·광고 ID를 수집하지 않습니다. 서버 접속 로그에는 IP에서 추정한 국가·지역·도시가 남습니다. 이 위치는 접속한 네트워크 기준이며 실제 위치와 다를 수 있습니다. 오류 기록은 기기 안에만 남으며, 이용자가 계정 탭에서 직접 복사해 보낼 때만 회사에 전달됩니다. 기기 알림은 기기 안에서만 예약합니다.

정책 페이지는 GitHub Pages에서 제공합니다. 페이지에 접속하면 IP 주소와 요청 정보가 호스팅 제공자에게 전달될 수 있습니다. 지원·삭제 요청 이메일을 보내면 회신에 필요한 이메일 주소, 문의 내용과 직접 첨부한 자료를 받습니다. 이 정보는 문의 처리와 결과 안내를 위해 사용하며, 처리를 마치면 지체 없이 삭제합니다. 비밀번호나 결제수단 정보는 보내지 마십시오.

2. 보유 기간

계정 식별자와 게임 기록은 계정을 삭제할 때까지 보관합니다. 게임 안에서 계정 삭제가 성공하면 즉시 삭제하며, 이메일 요청은 요청자와 대상 계정을 확인하여 접수 후 7일 이내에 처리하고 결과를 회신합니다. 상대방의 비무 방어 기록 등 삭제 후 남는 정보는 데이터 삭제 안내에 설명합니다. Supabase 무료 요금제에서 운영자가 조회하는 서비스 로그의 기본 보관 기간은 1일입니다. 회사는 이 로그를 별도 저장소로 내보내 보관하지 않습니다. 제공업체 자체의 보안·서비스 운영 기록은 Supabase 개인정보처리방침을 따릅니다.

수탁자업무보관 위치

4. 개인정보의 제3자 제공

회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 법령에 따른 요청이 있는 경우는 예외입니다.

5. 이용자의 권리와 계정 삭제

게임 안 계정 탭의 "계정 삭제"로 언제든 계정과 서버 기록을 지울 수 있습니다. 앱을 쓸 수 없으면 데이터 삭제 요청 페이지의 방법으로 요청할 수 있습니다. 열람·정정·처리 정지 요청은 아래 연락처로 보내 주십시오.

6. 만 14세 미만 아동

게임은 서버 계정(게스트)을 만들기 전에 만 14세 이상인지 확인합니다. 만 14세 미만이라고 답하면 서버 계정을 만들지 않으며, "오프라인으로 시작"으로 이 기기에서만 이용할 수 있습니다. 이 경우 계정과 게임 진행을 서버로 보내지 않습니다(앱 실행 때의 공지 확인 접속 기록은 1절과 같이 남습니다). 답은 이 기기에만 저장됩니다. 만 14세 미만 아동의 개인정보가 수집된 사실을 알게 되면 지체 없이 삭제합니다.

7. 안전성 확보 조치

서버와의 통신은 모두 암호화(HTTPS)합니다. 기기의 로그인 정보는 Android Keystore로 암호화해 보관합니다. 데이터베이스는 계정별 접근 제한을 적용합니다.

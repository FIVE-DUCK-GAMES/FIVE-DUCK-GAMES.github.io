1. 게임 진행과 저장
메테오 펀치(com.fiveduckgames.meteorpunch)는 회원 가입 없이 이용합니다. 골드, 캐릭터, 점수·훈장, 미션, 강화, 구매 권한과 옵션을 기기에 저장합니다. 자체 서버로 게임 진행을 전송하거나 클라우드 저장·온라인 순위를 제공하지 않습니다. 앱 데이터 삭제·앱 제거 시 진행이 사라질 수 있습니다. 운영체제 백업은 사용자의 기기 설정과 해당 제공자의 정책을 따르며 운영자가 열람하지 않습니다.

2. 광고
Google AdMob(Google Mobile Ads SDK)의 선택형 보상 광고와 플레이 종료 전면 광고를 사용합니다. SDK는 광고 제공·측정·부정 이용 방지 및 진단을 위해 IP 주소와 이를 바탕으로 한 대략적 위치, 기기·앱 정보, 광고 조회·클릭·영상 시청, 오류·성능 정보, 설정에 따라 허용되는 기기·앱 식별자를 처리할 수 있습니다. 광고 ID 권한 제거, 아동 보호 광고 요청, 일반 이용자용 광고 콘텐츠 등급 제한 및 게시자 자사 식별자 사용 중단 설정을 적용합니다. 이러한 설정이 모든 SDK 데이터 처리를 없애는 것은 아닙니다.
Google UMP를 통해 지역과 동의 상태에 필요한 광고 선택 사항을 처리합니다. 출동 보너스 화면의 ‘광고 동의 설정’에서 제공되는 선택 사항을 변경할 수 있습니다. 해당 지역이나 상태에서 별도 선택 화면이 필요하지 않으면 표시되지 않을 수 있습니다.

3. 구매와 복원
Google Play와 Unity In-App Purchasing을 사용합니다. 상품 ID, 주문번호, 구매 토큰, 구매 시각·상태 등 스토어가 전달하는 구매 정보를 기기에서 검증해 상품을 지급하고 중복 지급을 방지하며 구매 권한을 복원합니다. 자체 구매 검증 서버로 전송하지 않습니다. 카드번호나 결제 비밀번호는 운영자가 받지 않습니다. 스토어는 결제·환불·거래 기록을 별도로 관리하며 Unity IAP는 구매 흐름에 필요한 기술적 진단 정보를 처리할 수 있습니다.
Unity IAP 5.4 계열은 상품·거래 상태, 구매 금액·통화, 설치·세션 식별자와 기기·앱 정보를 Unity의 구매 서비스 제공·분석 및 진단 목적으로 전송할 수 있습니다. 자체 서버에서의 처리와는 별개이며 엔진 진단 설정을 끄는 것만으로 이 구매 SDK 전송이 모두 중단되지는 않습니다. 이 게임은 별도의 이메일 로그인이나 외부 웹 결제 기능을 제공하지 않습니다.
이 게임에는 Firebase Analytics·Crashlytics나 자체 플레이 분석 서버를 연결하지 않았습니다. 광고·결제 SDK의 처리와는 구분됩니다.

4. 고객지원과 웹사이트
이메일 문의 시 이메일 주소, 문의 내용, 자발적으로 첨부한 화면·주문번호를 문제 해결과 권리 요청 처리에 사용합니다. 비밀번호나 전체 카드번호는 보내지 마세요. 문의 자료는 해결에 필요한 동안 보관하며 삭제 요청을 받습니다. 법령에 따른 보존 의무나 진행 중인 분쟁으로 보관해야 하는 경우에는 해당 사유와 범위를 안내합니다.
안내 웹사이트는 GitHub Pages를 사용합니다. 접속 시 IP 주소와 요청 정보가 호스팅 제공자에게 전달될 수 있습니다.

6. 이용자와 보호자의 권리
이용자 또는 법정대리인은 위 고객지원 이메일로 열람·정정·삭제·처리정지 등 권리를 요청할 수 있습니다. 요청 내용 확인에 필요한 최소한의 정보를 안내하고 관련 법령에 따라 처리합니다. 별도 게임 계정이 없으므로 운영자가 보유하지 않는 기기 내 진행을 원격으로 조회하거나 삭제할 수는 없습니다.

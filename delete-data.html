개발자: FIVE DUCK GAMES
최종 갱신: 2026년 9월 15일

고양이 벌목단에서 이용자의 데이터를 삭제하는 방법입니다. 계정이 없는 게임이라 대부분의 데이터는 기기 안에만 있고, 직접 지우실 수 있습니다.

방법 1 — 기기에서 직접 지우기 (즉시)

게임 진행 상황은 이용자의 기기 안에만 저장됩니다. 아래 둘 중 하나로 즉시 삭제됩니다.

  1. 앱 삭제 — Android 홈 화면에서 고양이 벌목단을 길게 누르고 삭제를 선택합니다. 저장 파일이 함께 지워집니다.
  2. 게임 안에서 초기화 — 게임 실행 → 우측 상단 설정(톱니바퀴) → 처음부터 플레이 → 초기화 확인.

방법 2 — 서버에 저장된 데이터 삭제 요청

게임 안에서 순위 이름을 등록한 경우에만 서버에 데이터가 있습니다. 삭제를 원하시면 아래 순서대로 요청해 주세요.

  1. 게임 실행 → 설정 → 기록 → 순위 보기에서 본인이 등록한 순위 이름을 확인합니다.
  2. 아래 주소로 이메일을 보냅니다.
    받는 사람: fiveduckgames@gmail.com
    제목: [고양이 벌목단] 데이터 삭제 요청
    본문: 등록한 순위 이름을 적어 주세요.
  3. 개발자가 확인한 뒤 30일 이내에 삭제하고 회신합니다.

순위 이름을 등록한 적이 없다면 서버에 삭제할 데이터가 없습니다.
